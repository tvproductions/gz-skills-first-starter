  This does not prove the actual embedded XPPython3 runtime.

  Vulture's single production finding is the compatibility constant
  `UPDATE_SKILL_DESTINATION`, exercised by existing public-helper tests.
- Bandit reports five LOW findings, no MEDIUM/HIGH, no skipped checks: subprocess
  imports and fixed argument-list CLI execution, including git PATH lookup.
  These are reviewed CLI boundaries; no shell execution is introduced. The
  finding-bearing scan is not reported as a clean Bandit exit.
- Both independently exported, hash-checked dependency inventories pass pip-audit
  with no known vulnerabilities. This is a dated advisory observation.
- Cosmic Ray 8.7.0 bounded compatibility proof passes on actual Python 3.14.10:
  structured killed/survived controls and failing-baseline checks, not merely
  process exit codes. This is not a production mutation score.
