native configuration idempotence, explicit release-scope/version decisions and
clarified Python-policy ownership. Preserve exact managed Python families and
patches, package locks, project activation, user settings and plugin selections.

selected minor bundle, not the entire future roadmap. No newly written major
PRD is required for this pre-1.0 minor.

their own authorities; copied configuration does not establish acceptance.

dependency, native plugin installation, dependent-repository edit, registry
upload or Backplane activation is part of this publication.
